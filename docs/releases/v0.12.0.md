# Agent Triage v0.12.0 预览候选

这一版把 V5 多下游观测放进演示包。商品服务新增 `/api/checkouts/demo`，一次请求分别调用库存和分配服务；Agent 页面选择“Starter 商品服务”后，可以查看两个下游各自的请求数、超时、p95 和响应类别。库存变慢时，诊断只把有计数的超时归于库存。原来的商品查询、数据库、工单和订单演示仍保留。

完整解压 `agent-triage-0.12.0-demo.zip`，使用 JDK 21 运行 `start-demo.ps1` 或 `bash start-demo.sh`。首次使用固定规则，不需要模型密钥。在首页选择“Starter 商品服务”，点击“正常结算”或“库存超时结算”，然后点“开始排查”。页面会显示本次结算数和库存超时数；库存场景在请求后复位。V5 结果把库存和分配服务分开显示。换用其他基础端口时，仍从启动器给出的 Agent 地址打开页面。

候选附件为演示 ZIP、Starter JAR/POM、可选 Java Agent JAR 和 `SHA256SUMS.txt`。打包器只收录白名单文件，排除运行数据、日志和模型密钥；校验器还检查 V5 Starter 类、结算控制器、服务登记和同包源码提交。Starter 仍未发布到 Maven Central，其他应用的接入配置见[多下游说明](../MULTI_DOWNSTREAM.md)。

从旧预览版升级时，先结束在途操作并停止旧进程，备份数据目录和 `data/model-config.key`，再使用新包读取同一份数据。v0.6.0、v0.10.0、v0.11.0 的历史、服务配置和本地模型选择已在 Windows/Linux 的隔离环境中做过升级回归；不要把真实密钥交给演示脚本。

这是候选包，尚未建立正式 v0.12.0 Release 标签。公开 Petclinic REST 的 V5 接入和 60／300／600 秒同机成本对照已通过；小时级稳定性、Windows 长时宿主调度问题和生产环境开销仍未完成验收。候选构建及升级工作流见 [PR #3](https://github.com/MoChiUaena/agent-triage/pull/3)。
