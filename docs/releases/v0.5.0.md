# Agent Triage v0.5.0

这一版把普通请求异常的源码版本核对扩展到 MVC 处理类之外。Starter 仍可单独接入；需要核对其他业务类时，可选用独立的 `-agent.jar` 在启动业务应用时加载。它只查询当前 JVM 已加载的类，不转换业务字节码，也不动态附加到运行进程。

只有类名在进程中唯一、加载器与模块信息一致，且构建清单和类文件都通过校验时，异常帧才显示源码摘要一致。重复定义的同名类、缺少清单或无法确认的帧保持未知。单实例 Starter 每秒最多自动枚举 20 次，超出时不复用旧结果。[Petclinic 跨类验收](../validation/2026-09-30-petclinic-agent-class.md)和[连续查询测量](../validation/2026-09-30-runtime-class-lookup.md)记录了适用范围；CI 环境的短时耗时不是生产延迟保证。

页面侧栏统一为服务排查、历史与统计、项目源码、模型设置四个固定入口。完整历史、筛选与分页在“历史与统计”页面；首页的“新建排查”移到标题旁。

## 附件与启动

发布附件包括演示 ZIP、独立 Starter JAR/POM、可选 Agent JAR 和 `SHA256SUMS.txt`。ZIP 内也带有这三个 SDK 文件；独立 Agent JAR 不含 Spring 或业务类。首次运行演示仍只需 JDK 21，不需要模型密钥，也不需要开启 Java Agent。解压后运行 `start-demo.ps1` 或 `bash start-demo.sh`；端口和源码演示流程与 v0.4.0 相同。

在自己的 Spring Boot 应用中使用时，业务依赖 Starter `0.5.0`。如需跨类异常核对，再把同一次构建的 Agent JAR 加到 JVM 启动参数；配置及构建源码清单步骤见 [Starter 接入](../STARTER.md)。Agent JAR 不会替代 Starter 依赖。

升级前停止旧进程，备份 H2 的 `data/triage.mv.db` 与 `data/model-config.key`，或备份 PostgreSQL 数据库。历史记录和模型设置继续保留；可选 Agent 默认不启用。v0.4.0 标签与附件保持原样，旧包仍可用校验脚本核对。

本项目仍面向本机单实例，只读排查不执行修复。模型调用可能产生服务商费用；源码摘要不能证明应用运行时的热替换字节码或被业务代码改写过的异常栈。
