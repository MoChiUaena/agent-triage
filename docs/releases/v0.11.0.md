# Agent Triage v0.11.0

这一版增加无需下游占位配置的入站请求观测，并把请求执行异常、HTTP 错误响应与数据库侧判断分开。

- `HTTP_REQUESTS` / `HTTP_REQUESTS_V4` 只采集应用请求，下游耗时和超时保持未采集。
- 可选请求失败分类记录执行异常、单纯 5xx、异步超时、异步错误和已处理异常。计数、响应、事件与规则一致时才确认请求执行阶段异常；这个判断不确认业务、网络或数据库内部根因。
- 请求或池采样被容量淘汰、过期后读取旧窗口时返回 422，停止采用残缺数据；时钟回拨不恢复已丢失样本。
- 关闭执行器时取消排队任务并释放登记。请求完成后释放处理类引用，迟到观测不改变冻结窗口。

## 附件

`agent-triage-0.11.0-demo.zip`、Starter JAR/POM、可选 Java Agent JAR 和 `SHA256SUMS.txt` 共五个附件。JDK 21 即可运行演示；Linux/macOS 另需 Bash 和 curl。完整解压后运行 `start-demo.ps1` 或 `bash start-demo.sh`。新开关默认关闭，接入方法在包内 `OBSERVATIONS.md`。

## 从旧预览版升级

从 v0.6.0 或 v0.10.0 升级前，先完成在途操作、停止旧进程，备份数据库与 `data/model-config.key`。将原数据、同一密钥和自定义服务配置放入新包，再核对端口与源码目录。旧历史不会补零或自动清理；已选模型仍可能保持启用。旧包与备份应保留到验收完成。

## 验证与限制

本版通过 Windows/Linux 的同包运行和两条升级基线验收，也复验了固定 Petclinic 与 Petclinic REST。测试只使用固定规则或本地模型协议服务。数天稳定性、原生内存、其他 HTTP 客户端、多数据源、非回环地址和多实例仍未完成验证；当前未发布到 Maven Central。
