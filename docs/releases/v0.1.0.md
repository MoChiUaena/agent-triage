# Agent Triage v0.1.0

首个本地演示版本。订单服务通过 HTTP 调用独立库存服务，页面可生成正常请求与库存超时请求，再查询窗口指标、错误事件和排障文档。

下载 `agent-triage-0.1.0-demo.zip`，完整解压后用 JDK 21 启动三个服务，无需 Maven、数据库服务器或模型密钥。Windows 运行 `start-demo.ps1`；macOS/Linux 运行 `bash start-demo.sh`。默认地址 `http://127.0.0.1:18080`，Ctrl+C 停止本次启动的服务。

首次启动使用固定规则与真实本地 HTTP 观测。需要模型时，可在页面添加、测试并启用服务；API Key 在本地加密保存，真实模型调用可能计费。数据库和日志留在解压目录，发行包不包含本机数据或凭据。

主要功能：

- 三个只读工具、SSE 进度、证据引用、历史记录，H2 / PostgreSQL 存储。
- 页面模型配置，提供百炼、GLM、Kimi、DeepSeek 和兼容接口预设。
- 参数整批校验、一次参数更正及证据完整性反馈，均受原有次数和时限约束。
- 证据齐全后关闭工具选择；应用生成关键结论，排序并展示候选检查项中的前两项，保留原始选择。

验证：主项目 138 项测试，订单与库存服务各 1 项 HTTP 集成测试；Windows、Ubuntu、PostgreSQL 与 LIVE 协议 CI 通过。解压包分别用 PowerShell 与 Bash 启动，完成空窗口、正常与超时检查，退出后三个端口关闭且数据保留。最新六例留出对照有四条符合契约、两条应用证据不足，没有失败。

`agent-triage-demo.mp4` 是约 50 秒无声演示：前半记录固定规则模式下的实际请求、证据与执行过程，后半回放已保存的真实百炼结果，不重新请求模型。完整标识符已在画面中脱敏。`SHA256SUMS.txt` 可核对压缩包与视频。

这是早期预览版本，只支持订单/库存样例，没有多用户登录和生产观测适配。真实凭据目前只验证了百炼；小样本结果不代表生产准确率。结论措辞和建议排序属于应用策略，不能据此确认库存内部根因或服务整体健康。
