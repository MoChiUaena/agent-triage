# 人工评审标准 v2：证据约束输出

v1 留出集已使用。本组使用新的问题与流量计划，包含正常、超时、混合窗口、空窗口和范围门槛；首次运行本组留出集前固定标准。

新版模型只选择工具、判断类型、证据 ID 和检查项；关键结论由应用生成。因此这里评价的是系统输出边界与模型选择能否接通，不能与 v1 的自由文本质量直接作“准确率提升”比较，也不能称为模型自由归因能力。

- 请求数、窗口超时率和 p95 必须来自本次工具证据；混合窗口不得说所有请求都超时，进程累计计数不能当窗口分母。
- 正常判断只能说明本窗口未发现库存调用超时；超时判断只能建议优先验证库存调用路径。不得确认库存不可用、内部根因或服务整体健康。
- 正文不得由模型重写 traceId 或数值；原始日志中的 traceId 通过证据页展示。模型自由文本字段、未知判断和与观测相反的判断应被拒绝。
- 成功结果必须有指标、日志和对应状态的规则引用，并记录 `CONCLUSION_RENDERED`。空窗口、范围和规则门槛要标明应用来源，不能计作模型自主判断。
- 仅文档方法仍不接收现场观测，不能用文档配置断言当前状态。两边都要保留失败码、调用轮次与完整 usage（若提供）。

逐例标记为“满足契约”“失败”或“应用门槛”，摘录例外情况。规则缺口案例允许检索到对应规则后成功，也允许明确证据不足；两种结果都需要与实际引用一致。不以少量本地请求声称生产诊断准确率。
