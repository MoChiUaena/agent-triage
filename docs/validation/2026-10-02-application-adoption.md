## 改动与边界

Petclinic 的 `/owners/` 原有接口验证正常页、主人详情、普通异常与源码入口。JPA 验收额外包装数据源，使用专用单连接池和辅助故障入口核对 SQL 执行、获取连接超时与恢复。这些故障参数只用于验收；真实接入应保留原应用的 Hikari 配置绑定、池大小、超时和关闭顺序。

REST 的原有主人接口验证实际计数、404 与源码入口。辅助类默认关闭，验收中才启用业务异常、下游超时、Callable、显式包装的 DeferredResult、并发与迟到调用。辅助入口验证采集机制，不表示原项目本身存在这些故障；原有 404 仍不提供足以判断业务根因的异常位置。

本次变更只整理文档，未改变采集、诊断、模型或数据库行为。源码与构建摘要复验使用隔离副本，运行 JSON、数据库、密钥、日志和外部项目源码没有提交；已有发布标签和附件不变。

接入操作与已知成本集中在[应用接入说明](../APPLICATION_ADOPTION.md)。核对结果支持下一阶段先处理无 HTTP 下游的入站请求模式，再增加有明确证据门槛的请求执行阶段失败判断；更换框架、客户端、数据库驱动和拓扑分别验收。
