# Feign 出站观测验收

源码提交 `47b4929`。本机使用 JDK 21、Spring Boot 3.5.16、Spring Cloud OpenFeign 4.3.0 和 Feign Core 13.6，`integrations/pom.xml verify` 通过。[跨平台 Verify](https://github.com/MoChiUaena/agent-triage/actions/runs/38195803700)、[容量检查](https://github.com/MoChiUaena/agent-triage/actions/runs/38195803643)、[HTTP 短时资源检查](https://github.com/MoChiUaena/agent-triage/actions/runs/38195803667)和[Agent/Starter 运行资源检查](https://github.com/MoChiUaena/agent-triage/actions/runs/38195803645)通过。

测试应用启动 Spring Boot Servlet 上下文，并通过 Spring Cloud 管理的 `@FeignClient` 请求本机回环下游。正常请求进入下游耗时窗口；响应头和正文读取超时各计一次。直接 Feign Client 测试另核对普通 503 与连接拒绝不算超时、原异常与响应关闭、其他 origin、无 Feign 类路径和请求结束后的迟到正文读取。观测结果没有保存测试 URL、查询值或正文。

Starter 的 `feign-core` 依赖是可选的；`catalog-service` 的可执行 JAR 未打入 Feign、Spring Cloud OpenFeign、WebFlux 或 Reactor Netty。当前接入仅覆盖 Spring Cloud 管理的同步 Feign 客户端、一个已配置的下游 origin 和有效 MVC 请求；跨 origin 重定向的最终地址没有单独核对。手动 `Feign.builder()`、异步 Feign、远程网络及长期吞吐尚未验收。已发布的 v0.11.0 附件不含本次源码改动。
