# 接入本机 Java 源码

打开“项目源码”页面，填写项目名称、本机目录，并绑定一个已登记的服务。返回排查页，勾选“本次检索源码”后，结果中的“代码引用”会显示候选文件、方法、接口路径和代码片段。独立工单项目的复现方式见下方。

服务观测接入和源码登记是两件事。只登记源码不会产生运行指标；实际服务仍需通过 [Starter](STARTER.md) 或[只读观测接口](SERVICE_INTEGRATION.md)接入。源码可以辅助定位需要检查的代码，不能证明某个方法执行过，也不能据此确认运行根因。

项目卡片可以修改名称、目录和服务绑定。修改目录会先索引新目录，成功后再替换原登记；读取失败时保留原项目。解除绑定后仍可本机检索，也可以再次绑定服务。修改、解绑和重新索引会更新项目版本并关闭旧模型授权。删除索引需要确认项目与版本，只删除登记和索引，源文件与历史排查片段仍保留。

## 索引范围

索引使用 JDK 21 的语法解析接口，不编译项目、不加载项目类、不执行注解处理器。依赖缺失不会阻止语法解析；语法错误文件会跳过。当前提取类、方法、调用名称和 Spring MVC 注解中的首个静态路径，不做类型解析、完整调用图或跨服务追踪。

只读取 UTF-8 的 `.java` 文件。跳过 `.git`、`.idea`、`.gradle`、`target`、`build`、`data`、`logs`、`node_modules`、`dist` 和 `.env` 目录，以及链接文件和链接目录。疑似含常见硬编码凭据的 Java 文件会整体跳过；该检查不能覆盖所有敏感内容。

每个服务绑定一个项目，最多登记 20 个。单项目最多 2000 个 Java 文件、20 MB、10000 个符号，索引时限 30 秒；单文件不超过 256 KB。较大仓库可以登记一个模块目录。

本地数据库保存路径、符号、行号和文件 SHA-256，不保存完整源码。检索按问题、错误事件和对应观测的调用关键词返回最多 5 个候选。片段最多 80 行、3600 字符；读取时核对文件摘要，代码变化后需要重新索引。历史排查会保存当时展示的片段，便于复查。

## 模型读取

默认只在本机检索。模型读取需要同时满足：

1. 在模型设置页启用已保存的模型服务。
2. 在项目源码页确认接收服务、模型、配置版本和片段范围。
3. 在本次排查中勾选“本次允许模型查看候选代码”。

项目授权绑定模型服务 ID、配置版本和源码索引版本。切换模型或更新配置后，旧授权不适用；重新索引会关闭授权。提交任务后再次检查授权和文件摘要，未经允许的代码不会进入运行诊断的模型消息。

运行判断完成后，剩余轮次与时长允许时，另发起一次候选选择请求，包含最多 5 个验证过的片段、问题和相关观测。模型只能选择其中最多 3 个引用 ID，不能请求额外路径、执行项目或生成自由归因。无效引用、超时或轮次不足会保留运行判断和本机候选。关闭授权无法收回已经发出的请求。

源码管理、排查记录和 SSE 结果只允许本机同源访问，不提供远程代码上传或仓库克隆。`data/`、`target/`、日志与本地密钥不应提交到版本库。

## 独立验证

`verification/ticket-service` 是单独的 Spring Boot 工单应用，通过 Starter 记录同步 HTTP 调用。验证脚本启动自己的工单 JVM、分配接口和 Agent JVM，复制一份源码到忽略的 `target/source-smoke/`，不依赖已经运行的订单、商品或数据库样例。

```powershell
.\mvnw.cmd verify
.\mvnw.cmd -f integrations/pom.xml verify
python scripts/source_integration_smoke.py
```

脚本检查正常请求、两次实际 HTTP 超时、Controller 路径、Gateway 调用位置、片段行号、修改文件后的拒绝、重新索引和历史片段。该脚本不请求付费模型。`SourceIntegrationTest` 另用本地协议服务检查双重授权、旧授权失效、无效引用、轮次限额和超时；这些验证说明接口行为，不代表真实模型的代码定位准确率。
