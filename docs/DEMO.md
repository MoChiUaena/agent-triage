# 演示录像

[播放或下载 MP4](assets/agent-triage-demo.mp4)，约 50 秒，1280×800，无声字幕。

前半是实际操作录屏：生成正常请求、触发库存响应变慢、开始排查、展开指标和错误事件、查看执行记录与历史。使用独立 H2 内存实例和固定规则模式，不消耗模型服务费用；订单与库存是两个独立 Java 进程，发生真实 HTTP 请求与超时。

后半回放 2026-09-28 保存的百炼模型结果。画面标明这是历史，不重新调用模型，其他本机历史已从录制页面隐藏。模型选择工具和证据，应用生成结论并排序显示两项建议；没有录制设置页、Key 或模型内部思考。完整 traceId 在画面中显示为“已脱敏”。

录像工具属于可选开发辅助，不是应用运行依赖。复录时需要 Node.js、Playwright 与 `imageio-ffmpeg`，使用 `scripts/record_demo.cjs` 和 `scripts/render_demo.py`。录制实例必须为独立的 `DEMO + LIVE`，模型片段只读取已结束的执行。原始 WebM、媒体工具和本机执行 JSON 留在被忽略的 `target/`。
