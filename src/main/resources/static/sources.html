项目知识

导入本机 Markdown / TXT 或登记 GitHub 仓库固定提交中的根 README 与 docs/。全部在本机整理，不执行文档指令、不调用模型；资料外发默认关闭。

每次最多 100 个文档、单文件 256 KiB、总计 2 MiB、1000 段、每段 2000 字符；最多遍历 5000 条目 / 20 层。排除日志、构建目录、凭据、二进制和链接。预览最多缓存 10 份、十分钟有效；2 个并发预览读取，1 个导入执行、4 个排队。

预览后会显示规范化的准确目录和文件清单；不接受网络路径、磁盘根目录和链接。

来源管理（最多显示 100 个）

更新会保留历史文档；解绑与软删除立即停止新检索与材料发送，历史引用保留。重新绑定或重新导入须新预览。取消、失败和重启中断均不会切换当前有效版本。

允许模型读取候选代码

开启后，排查页仍需勾选“本次允许模型查看候选代码”。每次最多发送 5 个片段，每个不超过 80 行、3600 字符，以及相关运行观测。请求可能产生费用。

模型服务或配置版本变化、重新索引后，需要再次授权。疑似包含凭据的文件会跳过，但这不能代替你检查代码中的敏感内容。

修改项目

修改目录会重新索引；修改项目后，旧模型授权会关闭。选择“暂不绑定服务”仍可保留本机检索。

删除本地索引

删除该项目的登记与索引，源码文件和已保存的历史排查仍保留。之后可以重新登记项目。
