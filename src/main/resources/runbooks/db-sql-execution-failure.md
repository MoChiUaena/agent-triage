# SQL 执行阶段失败

文档 ID：DOC-DB-SQL-EXECUTION-FAILURE#v1。

获取连接成功后，`Statement.execute*` 返回异常，才记录为 `SQL_QUERY_FAILED`。窗口查询失败次数和同窗口错误事件一致时，可以确认本次观测到 SQL 执行阶段失败；它与获取连接超时属于不同阶段。

先按错误 traceId 找到对应请求，再检查应用侧 SQL、参数、事务和数据库错误详情。观测接口不保存这些内容。单次失败不能直接归因于锁等待、语法、索引、数据库负载或连接池耗尽；较高的查询 p95 也不足以证明具体原因。

若同一窗口还出现获取连接超时或失败，应分别核对两类证据，不将混合故障简化成单一 SQL 结论。修复后用新的请求窗口验证执行恢复。
