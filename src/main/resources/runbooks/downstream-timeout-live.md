# 下游读取超时排障

文档 ID：DOC-DOWNSTREAM-TIMEOUT#v2。适用服务：本仓库的 order-service 样例。

订单查询通过 HTTP 调用库存接口。样例的订单客户端请求总时限为 300ms；库存接口的超时场景会延迟 600ms。当前是否真的发生超时，必须看本次窗口采集的指标和错误事件，不能仅凭这段配置推断。

若订单与库存调用耗时升高、超时率大于零，且错误事件带有对应 traceId，可优先检查库存调用路径。下一步应核对库存接口处理耗时、客户端请求时限以及同一 traceId 的请求。

样例没有采集 CPU、连接池、网络和数据库指标，无法仅凭现有证据断言最终根因。
