# 请求执行阶段异常

文档 ID：DOC-REQUEST-EXECUTION-FAILURE#v1

只有同一服务和时间窗口内的请求执行异常计数大于零，响应分类有配套的 5xx 或未知值，错误事件包含 REQUEST_EXECUTION_FAILED，并选择本规则时，才能确认本窗口请求执行阶段发生异常。

单纯返回 5xx、异步超时、异步错误和已处理的客户端异常不是同一种证据。缺少分类、错误事件、匹配计数或规则时，保持证据不足。异常穿过过滤器后才生成错误页的请求，响应分类仍可能未知。

该判断只确认异常所在阶段，不判断业务条件、网络、下游服务、连接池或数据库内部根因。用本次错误事件和本机源码位置继续核查，不执行自动修复。
