# 连接池耗尽

文档 ID：DOC-DB-POOL-EXHAUSTION#v1。

获取连接超时与 SQL 执行失败发生在不同阶段。只有窗口内出现获取连接超时、采样时已用连接达到池上限并有等待线程，同时存在对应获取连接超时事件，才支持“连接池耗尽影响请求”的判断。仅有较高 p95、满载峰值或 SQL 报错都不够。

先用错误 traceId 对照获取连接阶段，再检查持有连接的请求、长事务、连接是否及时关闭及池容量。不能从池满直接推断连接泄漏或数据库不可用，也不能直接建议扩大池容量作为已确认修复。

峰值和采样计数只覆盖本次窗口，不代表当前仍然耗尽。累计请求数不能作为窗口超时率的分母。采样未捕获池满与等待重叠时，应保留证据不足。
